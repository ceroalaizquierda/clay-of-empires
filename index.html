Clay of Empires

Prototipo para probar controles táctiles y de escritorio. Defendé tu base y destruí la del rival. Elegí abajo la civilización de cada uno.

Seleccionar

  • Tocá una unidad o edificio para elegirlo.
  • Doble toque en una unidad: elige todas las de ese tipo en pantalla.
  • Mantené presionado y dibujá un contorno: al soltar se elige todo lo de adentro.

Dar órdenes

  • Con tropas elegidas, tocá el suelo para moverlas, un enemigo para atacarlo.
  • Con paisanos, tocá un árbol, una mina, un arbusto o un animal para juntar recursos.
  • Formar: activalo y dibujá una línea (fila o arco) o una figura cerrada (bloque, círculo).
  • Construir: elegí aldeanos y tocá Construir; el edificio queda en el centro de la pantalla: mové el mapa hasta el lugar (verde = se puede) y tocá ✓. Casas: población. Cuartel: infantería y tiradores. Establo: caballería. Torre: dispara sola. Molino / Kura: depósito de comida; tocándolo se cultivan campos (hasta 3 aldeanos trabajan adentro; se agotan y se resiembran).
  • Investigación: dos ramas en dos edificios. Militar (Academia / Heigakusho): armas, armaduras, movilidad, inteligencia y tácticas. Tecnología (Taller / Gakumonjo): agricultura, herramientas, construcción y organización. Las marcadas con ◆ son doctrinas: elegir una cierra la otra.
  • Edades: con 3 investigaciones (de cualquier rama) tu base puede pasar a la edad II, y con 7 a la III. Cada edad desbloquea tropas y edificios.
  • Tocá tu base (Cabildo o Castillo) para entrenar aldeanos y avanzar de edad; las tropas se entrenan en el cuartel y el establo. Plasgentina: paisanos, gauchos, boleadores (tiran a distancia y enredan: frenan a la caballería) y granaderos. Japón: campesinos, ashigaru, arqueros, samuráis y jinetes.

Cámara

  • Arrastrá con un dedo para moverte, pellizcá con dos para acercar o alejar.
  • Grupo 1 y 2: mantené para guardar la selección, tocá para elegirla.

Teclado y mouse

  • Clic izquierdo para seleccionar; Mayús + clic suma o quita una unidad. Arrastrá para seleccionar un rectángulo; con Mayús, se suma a la selección actual.
  • Clic derecho da una orden a las unidades elegidas: mover, atacar, recolectar, construir o reparar.
  • Rueda para acercar o alejar; arrastrá con el botón central o con Espacio + botón izquierdo para mover la cámara. También podés usar WASD o las flechas.
  • Ctrl + Mayús + 1/2 guarda el grupo; 1/2 lo selecciona. Esc cancela Formar o limpia la selección.
